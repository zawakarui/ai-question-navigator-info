AI質問ナビゲーター

Chrome Extension · v1.3.1

AIとの長い会話に、ナビゲーションを。

Claude / ChatGPT / Gemini / Perplexity の質問を自動検出し、サイドバーでワンクリック移動。

Chrome Web Store で追加 無料 · Manifest V3 準拠
対応サービス
Claude ChatGPT Gemini Perplexity

機能

01

4 つの AI サービスに対応

Claude / ChatGPT / Gemini / Perplexity の 4 サービスに対応。サービスごとのテーマカラーで一目で識別できます。

Claude ChatGPT Gemini Perplexity
02

質問の自動検出 & コピー

会話の中の質問を自動でリスト化。クリックで該当箇所へスムーズスクロール、Shift+クリックで質問と回答を Markdown 形式でコピーできます。

03

サイドバーを自由にカスタマイズ

ドラッグで位置移動、角ドラッグでサイズ変更、最小化で省スペース表示。起動時から最小化状態で開くオプションも選べます (v1.3.1)。

利用手順

01

Chrome Web Store からインストール

02

Claude / ChatGPT / Gemini / Perplexity を開く

03

サイドバーで質問をクリック

プライバシー、最優先。

データ収集なし・外部送信なし・すべてローカル処理。詳細はプライバシーポリシーをご覧ください。
